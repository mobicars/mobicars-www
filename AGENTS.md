## Interactive UI: React Aria first

Build buttons, choices, cards to pick, lists, fields, dialogs, tooltips and disclosures with `react-aria-components` first. Write a control by hand only when React Aria has nothing for it, and say why in a comment. Which component fits which case, and the rules learned in this project, are in `.agents/skills/mobicars-react-aria/SKILL.md`.
